Install Muse

A local Mac assistant: Bonsai 2 4B answers, Argmax turns speech into text, and the browser harness reads mail and the web. Everything runs on this Mac and answers with Wi-Fi off. Apple Silicon and macOS 15 or later.

Before you start. Each Mac needs its own Argmax key (ax_…) and secret token (axst_…), from app.argmaxinc.com. Don't use someone else's.

The first voice start on a new Mac takes several minutes while macOS compiles the speech model for the Neural Engine. It happens once. Leave Muse running until voice is ready.

This disk image holds only Muse.app, this page and setup.sh. No models, keys or mail are in it. Each part below is installed on its own. Pick one of the two paths.

Path 1: one command

setup.sh does the steps in Path 2 in order. Read it first; it's short. It prints each command before it runs it, asks before every download or install, skips what's already there, and never uses sudo.

bash /Volumes/Muse/setup.sh

It installs into ~/ai-hackathon-26. To use another folder: MUSE_DIR=~/somewhere bash /Volumes/Muse/setup.sh. Then go to step 10 below.

Path 2: do it yourself

  1. Xcode 16 or later, for building the voice program. Xcode on the App Store. Open it once to finish installing.
  2. uv, the Python package manager. docs.astral.sh/uv 
    curl -LsSf https://astral.sh/uv/install.sh | sh
  3. The Muse code. github.com/cobylai/ai-hackathon-26. It's private, so ask Coby for access. 
    git clone https://github.com/cobylai/ai-hackathon-26.git ~/ai-hackathon-26
cd ~/ai-hackathon-26
  4. Python packages and the harness's Chromium. Playwright browsers. Python 3.12 is pinned in .python-version. 
    uv sync
uv run playwright install chromium
  5. Bonsai 2 4B, the language model behind every answer. prism-ml/Ternary-Bonsai-2-4B-mlx-2bit (about 1 GB). It runs in its own Python env with mlx-vlm, in the folder samples/bonsai-models/mlx/. 
    cd ~/ai-hackathon-26/samples/bonsai-models/mlx
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -r requirements.txt
.venv/bin/hf download prism-ml/Ternary-Bonsai-2-4B-mlx-2bit --local-dir models/bonsai2-4b-mlx
cd ~/ai-hackathon-26
    Check it: scripts/serve_bonsai.sh 4B, then curl -s localhost:8080/v1/models in another window. Ctrl-C stops it; Muse starts it on its own later.
  6. Whisper speech model for Argmax. argmaxinc/whisperkit-coreml, folder openai_whisper-large-v3-v20240930_626MB (about 630 MB). 
    ~/ai-hackathon-26/samples/bonsai-models/mlx/.venv/bin/hf download argmaxinc/whisperkit-coreml \
  --include "openai_whisper-large-v3-v20240930_626MB/*" \
  --local-dir ~/Documents/huggingface/models/argmaxinc/whisperkit-coreml
  7. Argmax SDK login. app.argmaxinc.com: get your own secret token (axst_…, for the SDK download) and API key (ax_…, for Muse). 
    swift package-registry set --global --scope argmaxinc https://api.argmaxinc.com/v1/sdk
swift package-registry login https://api.argmaxinc.com/v1/sdk/login --token axst_YOUR_TOKEN
  8. Build the voice program (argmax-voice, about 1 minute). 
    cd ~/ai-hackathon-26/voice/swift && swift build -c release && cd ~/ai-hackathon-26
  9. Demo bank and demo calendar, so nobody's real mail or appointments show. 
    scripts/serve_bonsai.sh 4B &     # needed for filing; stop it after
uv run python scripts/make_test_mail.py write ~/muse-demo-mail --today $(date +%F)
MUSE_BANK_DIR=~/muse-demo-bank uv run python -m bank.load ~/muse-demo-mail --kind email
    In Calendar.app: File > New Calendar, name it Muse demo, and add a few made-up events.
  10. Open Muse. Copy Muse.app to Applications. If the code isn't in ~/ai-hackathon-26, tell Muse where it is: 
    defaults write local.ai-hackathon-26.muse MuseRepo /path/to/ai-hackathon-26
    Muse is signed with a Developer ID and notarized by Apple, so it opens with a double-click.

    At first launch, "Set Up Muse" walks you through one step per screen: privacy, your ax_ key (kept in your login Keychain), Accessibility (for Fn-Space), the microphone, then Calendar, Reminders and Mail. Then Muse starts Bonsai and its window server and lists anything still missing, each with its fix.

    Use it: tap Fn-Space (the Globe key and Space) to show or hide the panel; hold it to talk and let go to ask. Waveform icon in the menu bar: Open, Sync mail, Discover, Check setup, Quit.
