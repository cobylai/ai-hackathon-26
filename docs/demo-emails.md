# Demo emails

Eight made-up emails for the live demo. Send each one to
**ilovelocalai@gmail.com** (the throwaway test account), then run the sync:

```bash
FLUX_BANK_DIR=~/flux-bank uv run python scripts/sync_email.py 7
```

Apart from the partner's first name (Antranig) on emails 2, 4, 6 and 8, nobody here is a real person or real course staff. Courses and groups are
invented (e.g. "HIST 2290" does not refer to a real class). Dates assume the
emails go out on **Sat 2026-11-14**, so "the coming week" is Mon 16 to Sun 22.

Who sends: **Coby sends 1, 3, 5, 7. The partner sends 2, 4, 6, 8.** Paste the
subject and body exactly as written. Each email names its sender in the
sign-off, so the demo works whoever's address it comes from.
